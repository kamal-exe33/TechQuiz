## ✨ Features

- 📚 Seven technical quiz categories
- 🔀 Randomized questions and answer options
- ⏱️ 30-second timer per question
- ✅ Instant correct/wrong answer feedback
- 📊 Automatic score and percentage calculation
- 🏆 Category-wise best score tracking
- 💾 Recent history of the last 3 attempts
- 📱 Responsive design for desktop and mobile

## 📖 Quiz Categories

`HTML` · `CSS` · `JavaScript` · `C` · `Python` · `DBMS` · `DSA`

**Question Bank:** 70 questions — 10 per category.

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| HTML5 | Page structure |
| CSS3 | Styling and responsive layout |
| JavaScript (ES6) | Quiz logic and interactions |
| DOM API | Dynamic questions, answers and results |
| LocalStorage | Saving best scores and recent attempts |

## 🚀 Getting Started

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser, or use the Live Server extension.

No additional packages or build tools are required.

## 💾 Data Storage

TechQuiz uses browser LocalStorage to save category-wise best scores and the three most recent quiz attempts.

The data stays in the current browser and is not synchronised across devices.
